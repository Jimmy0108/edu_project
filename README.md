# EduBridge_AI

EduBridge_AI 是「知識圖譜驅動的課前診斷與課中認知鷹架」競賽原型。教師先上傳並確認教案與簡報，系統提出可追溯來源的概念圖譜、診斷題與支援卡；學生前測只形成暫時學習證據，授課時則以穩定概念比對顯示一張可自行展開的支援卡。

目前以「釣魚郵件與可疑連結辨識」作為 90 秒資訊科技微課。示範內容同時引用教師教材與事先查核的臺灣資安署、衛生福利部、CISA、NIST 官方頁面；不確定或來源不足的關係必須由教師保留為未確認，而不是由模型補寫。

## 專案結構

- `app/`：可執行網站、API、測試及競賽操作文件。
- `stitch_edubridge_ai_classroom_support/`：使用者提供的 Stitch 設計來源，不是執行時相依套件。
- `FUTURE_RAG_ROADMAP.md`：早期研究與未來擴充筆記；現行產品以知識圖譜負責教學決策，來源檢索負責證據追溯，兩者互補。
