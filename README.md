# EduBridge_AI

EduBridge_AI 是「課堂中即時認知鷹架」的競賽原型。教師語音先成為所有學生都可見的逐字稿，再依學生自行選擇的呈現偏好，產生視覺重點、閱讀鷹架與專注節奏三種結構化內容。

本版以「釣魚郵件與可疑連結辨識」作為資訊科技課程的安全示範情境；它不改變產品定位，僅用於展示同一套資料流可套用到不同學科。

## 專案結構

- app/：正式可執行網站與 API。
- stitch_edubridge_ai_classroom_support/：使用者提供的 Stitch 設計來源，不是執行時相依套件。

請在 app/README.md 依照本機啟動、設定金鑰與測試步驟操作。
