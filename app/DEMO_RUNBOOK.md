# EduBridge_AI 競賽 Demo 操作手冊

## 建議故事線

先以競賽簡報說明產品，再切換到 90 秒「釣魚郵件與可疑連結」微課，實際完成課前圖譜、前測、授課與學生支援。

## 課前彩排

1. 執行 `npm run dev`，開啟 `/prepare`。
2. 按「快速展示」。內容包含教師教材，以及臺灣資安署、衛福部、CISA、NIST 的教學摘要、網址與查核日期。
3. 核對全部教材；按「建立知識圖譜」。無金鑰時會建立規則型草稿，不影響完整 Demo。
4. 在 SVG 圖譜點開至少一個節點，示範教師可修改節點、關係與來源，再確認教學頁面、題目與支援卡。
5. 調整三名匿名學生的功能偏好，發布到本機並匯出 JSON 備援。
6. 以學生 A、B、C 分別完成前測，刻意讓其中一人答錯「寄件者網域」。
7. 開啟 `/teach` 與三個 `/learn?stage=live&student=A|B|C` 分頁。

## 上台示範

1. 在教師頁切換一頁教學內容，再貼上內建講稿；第一次按「送出合格字幕片段」：只有字幕，畫面標示等待穩定。
2. 第二次按「再次確認同一概念」：概念穩定，學生端出現一個收合提示。
3. 學生自行展開，展示同一內容依偏好成為白話短句、單步支援或可朗讀內容。
4. 展開「為什麼現在顯示」，核對教師教材及官方來源。
5. 完成一題課中檢核，讓 `needs-check` 更新為 `developing`；再由教師人工確認或加入另一階段正確證據才成為 `ready`。
6. 展示教師「暫停 AI」及「手動指定概念」，說明教師始終保有控制權。
7. 展示字級、行距、逐行聚焦及色覺安全設定；關閉金鑰或網路後，使用已發布課程包、手動字幕及備援 JSON 完成同樣流程。

## 不應宣稱

- 不宣稱零幻覺、正式診斷、取代教師或已證實提升學習成效。
- 不把一次答錯稱為「不會」或「能力不足」。
- 不把規則型草稿或預載卡片說成當場生成。
- 不把官方來源連結等同整個知識圖譜均已由官方認證。

## 驗收

執行 `npm run lint`、`npx tsc --noEmit`、`npm test` 與 `npm run test:e2e`。瀏覽器測試會使用本機 Chrome／Edge，自動驗證課前建立、發布、兩段穩定辨識、學生支援卡、偏好保存及模擬 200% 縮放。另以正式展示電腦人工檢查：實際麥克風權限、三分頁 BroadcastChannel 即時同步、朗讀聲音、離線備援及外部來源網址。
