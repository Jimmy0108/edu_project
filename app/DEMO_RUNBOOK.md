# 競賽報告就是示範課：操作手冊

本版為單堂課、同一台展示電腦的競賽原型。

## 課前準備

1. 在 app 目錄安裝依賴並執行 `npm run dev`。建議 Node 24；測試使用 Node 原生 TypeScript stripping。
2. 複製 `.env.example` 的欄位到 `.env.local`，設定伺服器端 `GROQ_API_KEY` 並重啟服務。雲端版本須另外設定 Sites 環境變數；本機檔案不會自動上傳。
3. 上傳正式競賽 PPTX 與講稿 DOCX，或先使用「載入競賽報告示例」。每檔最多 10 MB，每堂最多 200 段。
4. 檢查投影片順序、段落文字，修正後勾選確認。圖片式教材需另附文字；目前不處理 PDF、舊版 DOC/PPT、講者備註或 OCR。
5. 準備 3–5 段講稿。逐段送出並人工核對 AI 整理與來源，再匯出 JSON 備援。準備好的展示必須保留離線可啟動的本機服務；單靠雲端 URL 無法保證斷網時重新開頁。

## 上台示範

1. 說明「我們現在的競賽報告就是教材」。展示已確認的教材及來源。
2. 在同一瀏覽器另開三個學生端分頁，或直接切換頁首三種模式。BroadcastChannel 不支援不同裝置或不同瀏覽器。
3. 先用一段手動講稿驗證鏈路，再啟動麥克風。每約 10 秒完成一段錄音，辨識期間暫停收音，請配合畫面稍停。停止錄音會捨棄尚未送出的片段。
4. 展示字幕先到、三種鷹架後到；展開檢索來源並核對，說明引用仍需人工判斷。
5. 展示學生端字級、高對比、低干擾、暫停畫面、單步閱讀與朗讀。這些是自選支持，不是診斷工具。

## 備援與真實性

- 無 Groq 金鑰：語音不會傳出，手動字幕可用，本地分句會明示「未使用生成式 AI」。
- API 逾時、格式或引用 ID 不合法：字幕保留，退回原文分句。
- 現場網路異常：已開啟頁可勾選本地分句，或匯入課前 JSON 後回放。
- 回放明示「預錄結果回放」，不得說成當場生成。
- 免費服務額度取決於帳號；展示前須在自己的帳號試跑。沒有金鑰及真人音訊測試時，不宣稱已驗證真實語音／AI 效能。

## 工程驗證

執行 `npm test`、`npm run lint`、`npx tsc --noEmit`。自動測試涵蓋 Office 文字解析、重排投影片順序、確認篩選、詞彙檢索、輸出驗證、API 基本錯誤與无金鑰備援。仍需以正式簡報及現場設備進行收音、瀏覽器與引用正確性的彩排。

目前 RAG 是 TF-IDF 詞彙向量檢索，不是神經 embedding；未加入 PDF/OCR、每張卡逐句證據驗證、跨裝置連線及正式學生支持成效研究。
