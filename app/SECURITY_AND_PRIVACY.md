# 安全與隱私設計

## 資料最小化

- 不收集學生姓名、學號、診斷或身分資料。
- 匿名學生只保存字幕、白話短句、一次一步、色覺安全、朗讀、減少動態與進階挑戰等功能設定，不保存診斷名稱。
- 課程包、匿名前測證據與最近一個課堂畫面保存在同一瀏覽器 localStorage；可清除網站資料或匯出／替換課程包。
- Office 原檔在瀏覽器解析，不傳到伺服器；建立 AI 圖譜時，已確認教材文字會傳到本站 API。第三方服務保存政策須另行確認。

## 金鑰與網路

- GROQ_API_KEY 只可放在伺服器環境變數或 Cloudflare Secret，禁止放入前端、Git 或截圖。
- .env* 已被 Git 忽略；請以 .env.example 作為欄位參考。
- 未設定金鑰時，音訊端點回傳 503 並明示「不會外傳音訊」。
- API 僅接受允許的音訊 MIME type，單檔上限 25 MB。

## 內容安全

- 圖譜提示詞要求輸出僅根據已確認教材，且將教材視為資料而非系統指令。
- 節點、關係、題目與卡片都驗證來源 ID；引用存在不代表內容必然正確，發布前仍需教師確認。
- 課中不即時生成新的教學事實，只比對概念並選取課前已核准卡片；低匹配時只保留字幕。
- 資安教學畫面使用 .example 假網域與示意資料，不提供可點擊釣魚網址、惡意檔案或真實帳密。

## 上線前必要工作

1. 由學校或試辦教師確認錄音、第三方處理與資料刪除告知程序。
2. 設定 API 用量限制、錯誤監控及服務失效時的字幕／手動教學備援。
3. 對不同裝置、網路與繁體中文課堂語音進行延遲和辨識品質測試。
4. 進行真實教師與學生的可用性測試，再主張任何成效指標。
5. 正式校園版須加入明確保存期限、刪除入口、存取權限、家長／學生告知與學校核准程序。
