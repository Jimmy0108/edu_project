# 安全與隱私設計

## 資料最小化

- 不收集學生姓名、學號、診斷或身分資料。
- 模式僅代表自行選擇的資訊呈現偏好。
- 課堂資料暫存在頁面記憶體，關閉頁面即失去；使用者可自行匯出包含教材、字幕與生成結果的備援 JSON。
- Office 原檔在瀏覽器解析，不傳到伺服器；已確認教材文字會傳到本站 API，最多三段檢索結果送至 Groq。第三方服務保存政策須另行確認。

## 金鑰與網路

- GROQ_API_KEY 只可放在伺服器環境變數或 Cloudflare Secret，禁止放入前端、Git 或截圖。
- .env* 已被 Git 忽略；請以 .env.example 作為欄位參考。
- 未設定金鑰時，音訊端點回傳 503 並明示「不會外傳音訊」。
- API 僅接受允許的音訊 MIME type，單檔上限 25 MB。

## 內容安全

- 鷹架提示詞要求輸出僅根據教师逐字稿與已確認的檢索教材，且將教材與逐字稿視為資料而非系統指令。
- 來源 ID 有驗證，但引用存在不代表內容必然正確；仍需教師檢核。
- 無法由逐字稿支持的內容，應顯示「教師尚未在本段說明」。
- 資安教學畫面使用 .example 假網域與示意資料，不提供可點擊釣魚網址、惡意檔案或真實帳密。

## 上線前必要工作

1. 由學校或試辦教師確認錄音、第三方處理與資料刪除告知程序。
2. 設定 API 用量限制、錯誤監控及服務失效時的字幕／手動教學備援。
3. 對不同裝置、網路與繁體中文課堂語音進行延遲和辨識品質測試。
4. 進行真實教師與學生的可用性測試，再主張任何成效指標。
